# Hello — example TimesGate plugin

Shows a message on the five screens, one word per screen, in a colour that shifts every minute.
It's deliberately small: copy the folder, rename it, and change the id in `plugin.json` to start
your own plugin. See `PLUGINS.md` in the TimesGate folder for the full guide.

Install it from the page: **Plugins → Install**, choose a .zip of this folder (or put the folder in
`plugins/hello` and restart the server).
