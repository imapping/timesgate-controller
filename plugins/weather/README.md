# Weather

Current conditions (screen 1) and the forecast for today and the next 3 days (screens 2–5), from
Open-Meteo. It's free and needs no key. The icons are animated. When kept updated, it refreshes
every 30 minutes. Choose the place with the search box; it's saved in `data/weather.json`.

Weather data by [Open-Meteo.com](https://open-meteo.com/), licensed CC BY 4.0. The free API is for
non-commercial use (up to 10,000 calls a day; this plugin makes about 50).
