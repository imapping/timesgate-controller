Add a server

Put the health page on the server first (for IIS: health.ashx, see the Read me), then enter its address and the HealthKey from its web.config, from your computer (the one running the controller, or one it trusts; not a phone).

Limits and alerts

Screens: how many servers are up and which have problems · then a server each, the worst first (up to four): its CPU, memory and fullest disk, and anything else wrong (a database that failed, a restart Windows is waiting for). CPU counts as busy when the last three checks average over the limit. It checks every minute, even when something else is on the screens. The keys stay on the controller.
