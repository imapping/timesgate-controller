Settings

Times Gates

To add another Times Gate, press Find on network and pick it. The list at the top then switches which one this page controls; each keeps its own screens, timer, score and lights.

Buttons

Press a button (or move the joystick) on your button box — it appears here and lights up when pressed. Choose what a press does, and optionally something different when it's held for a second. Works with this page closed.

A plugin is code that runs inside the controller, on whichever computer runs it (a PC or a Raspberry Pi), so only install ones you trust. Installing or removing works from the computer running the controller, or one it trusts (such as the PC you set up a Pi from), or from any other device with the PIN. How to write a plugin →
